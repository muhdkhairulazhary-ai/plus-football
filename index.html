Pasang plus+ Football di iPhone

Buka laman ini dalam Safari, kemudian:

  1. Tekan butang Kongsi (kotak dengan anak panah ke atas).
  2. Pilih Add to Home Screen / Tambah ke Skrin Utama. Jika tersedia, aktifkan Open as Web App.
  3. Tekan Add / Tambah. Buka melalui ikon plus+ pada Skrin Utama.

Berita tersimpan boleh dibaca di luar talian selepas muatan pertama selesai. Skor, jadual API dan carian pemain memerlukan internet. iPhone boleh memadam storan laman; akses offline tidak dijamin.

Aplikasi sedang dibuka dalam mod standalone.
